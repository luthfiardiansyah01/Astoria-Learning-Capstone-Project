# Berkas Legacy

Berkas di folder ini bukan bagian dari test aplikasi atau pipeline CI saat ini.
Dipindahkan dari `tests/` agar tidak tercampur dengan unit, integration, dan E2E test.

- `database-runtime-build.sh`
- `python-runtime-build.sh`
- `python-runtime-container.sh`

Tidak dijalankan oleh `bun run test:*`. Pertahankan hanya sebagai referensi historis;
hapus jika sudah tidak diperlukan.
